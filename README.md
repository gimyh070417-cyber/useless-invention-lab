# 쓸데없는 발명소

로그인이나 서버 없이 브라우저에서 바로 쓰는 작은 발명 놀이터입니다. 재료 두 개를 조합해 발명을 적고, 카드로 간직해 보세요. 서랍은 현재 브라우저의 localStorage에 저장됩니다.

## 실행

index.html을 브라우저에서 열면 작동합니다. 정적 파일만으로 구성되어 빌드 과정이 없습니다.

## 배포

이 폴더를 정적 사이트로 올리면 됩니다.

- Cloudflare Pages: 프레임워크 프리셋 None, 빌드 명령 비움, 출력 디렉터리 .
- Vercel: 이 폴더를 프로젝트 루트로 선택하고 Framework Preset Other, 빌드 명령 비움, 출력 디렉터리 .

서랍의 발명품은 이 브라우저에만 저장됩니다. 브라우저 데이터를 지우면 함께 사라질 수 있습니다. 현재 버전은 공유 서버나 계정을 사용하지 않습니다.
